[h1]ApocalipseBR LoadGridSquare Optimizations[/h1]

Four optional fixes for Build 42 that reduce the work these mods do as new parts of the map load. They’re aimed at reducing server stutters while players travel or explore. You can enable just the fixes for the mods you use.

[h2]What each fix changes[/h2]

[b]LiuDing Tiles[/b]
Designed for the reviewed copy of Workshop item 3736154771. The author does not declare a mod version. The repository records the source file’s SHA-256.
[b]Before[/b] The mod searched each newly loaded square for decorative sledgehammers to turn into items you could pick up.
[b]Now[/b] The conversion runs when one of those sledgehammers actually loads. The item is placed at the right height before the server sends it to players, so it can sit on the furniture where it belongs.
Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3736154771]LiuDing Tiles[/url] ([b]LiuDing_Tiles[/b]). Enable [b]ApocalipseBR_LiuDingTiles_fix[/b].

[b]True Swimming[/b]
Originally designed for 1.9. The public Workshop build was verified with 1.11.
[b]Before[/b] The mod searched newly loaded squares for leftover invisible platforms it uses to let you swim. These can be left behind after an interrupted session or arrive with a newly loaded area in multiplayer.
[b]Now[/b] The mod removes a leftover platform when it loads. Swimming and walking in shallow water work as before.
Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3802372726]True Swimming by Harkwood[/url] ([b]TrueSwimming[/b]) and Build 42.20 or later. Enable [b]ApocalipseBR_TrueSwimming_fix[/b].

[b]Minidoracat Build Anything[/b]
Patch baseline [b]42.22.2-1.3.0[/b].
[b]Before[/b] Loading a new area could make the game check older player-built objects for repairs all at once, even when there was little to fix.
[b]Now[/b] Those checks are spread out as you play. The game remembers which areas have already been checked, so it can skip empty areas and go straight to known objects. Some repairs may finish shortly after you arrive. If you need to check your builds again, use [b]Reset Builder Migration Cache[/b] in the right-click menu in single-player or as a server admin.
Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3830045886]Minidoracat Build Anything for B42[/url] ([b]MinidoracatBuilderFor42[/b]), its dependencies, and Build 42.22.2 or later. Enable [b]minidoracatbuilderfix[/b].

[b]Basement Building[/b]
Patch baseline [b]1.6.13[/b].
[b]Before[/b] The mod searched newly loaded squares for basement ladders and records needed to restore missing basement rooms. Those checks ran even in areas with no basements.
[b]Now[/b] Ladder checks start when the game loads a matching ladder. Room recovery searches underground areas. If a repair needs a nearby area that hasn’t loaded yet, it can resume when that area loads.
Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3806513504]Basement Building by APAROSA[/url] ([b]aparosa_BasementDig[/b]) and Build 42.20.0 or later. Enable [b]apocalipsebr_basementdig_fix[/b].

[h2]How to install[/h2]
[list]
[*]Subscribe to this bundle and the original Workshop mods for the fixes you want. Enable each companion alongside its original mod. The fixes apply automatically.
[*]For a dedicated server, add the Workshop items to WorkshopItems and the corresponding mod IDs to Mods. Use the same enabled mods on the server and connecting clients.
[*]Use Build 42.22.2 or later for all four fixes together. Check the original mod’s requirements if you only use part of the bundle.
[*]Server admins can look for [b]startup OK[/b] in the server log to confirm each enabled patch initialized. Debug mode can stay off.
[/list]

[h2]How the Workshop download is built[/h2]
SteamCMD downloads the original Workshop mods at build time. The build applies the repository’s .patch files to MinidoracatBuilder and Basement Building and uses before-and-after Lua snippets for True Swimming. It tests the generated Lua and packages the complete replacement files you receive when you subscribe. The LiuDing Tiles fix ships the converter maintained in the repository.

[h2]For mod authors[/h2]
Open the patches folder in the GitHub repository to see the additions and removals with their surrounding context. For True Swimming, compare the before and after snippets. To review the complete Lua as shipped, subscribe to this bundle and open the companion’s 42/media/lua folder in the Workshop download. The LiuDing converter is under common/media/lua.
